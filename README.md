# 高中数学知识图谱

离线知识库。双击 `index.html` 即可打开，无需服务器。`index.html`、`katex/`、`img/`、`export-assets/` 必须留在同一目录。

## 规模

9 个模块、30 个主题、159 个知识点。结构化概念、定理和方法 2503 条，专题题型 646 个，专题例题 1938 道。

## 怎么看

- **知识体系**：模块 → 主题 → 知识点 → 概念 / 公式·定理 / 解题方法 / 典型例题。这是主图。
- **按教材刷**：保留教材顺序和讲义卡片。
- **覆盖体检**：检查题型、题目和知识点归属。

单击节点会把这一支展到底，再点一次收起。拖动平移，滚轮缩放。「只看本支」聚焦当前分支。「原书切片」把已有卡片切回原始版面图。

详情栏在桌面约占半屏。过长公式可在内容框内横向滚动。

## 文件

| 路径 | 作用 |
| --- | --- |
| `index.html` | 离线页面，内容已内嵌 |
| `专题数据/` | 159 个知识点的 JSON 与互链 |
| `img/` | 原书切片，题卡退回图片时使用 |
| `katex/` | 公式渲染 |
| `export-assets/` | 导出 PNG 时加载的离线资源 |
| `对照检查.html` | 原书切片与公式渲染并排核对 |
| `说明.txt` | 整理说明与重建方式 |

内容改 `专题数据/*.json`。结构（新知识点、主题内顺序、弱连线）在本地工作目录的结构文件里改，再重建页面。
