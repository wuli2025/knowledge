**1.B**

### 元素分析

第一电离能的变化规律：每个周期的第一种元素（氢或碱金属）的第一电离能最小，最后一种元素（稀有气体）的第一电离能最大；第ⅡA、ⅤA 族元素的第一电离能大于同周期相邻元素。元素 $a\sim i$ 为短周期元素，$f$ 的第一电离能最大，则 $f$ 为 $\mathrm{Ne}$，据此推出 $a$ 为 $\mathrm{B}$、$b$ 为 $\mathrm{C}$、$c$ 为 $\mathrm{N}$、$d$ 为 $\mathrm{O}$、$e$ 为 $\mathrm{F}$、$g$ 为 $\mathrm{Na}$、$h$ 为 $\mathrm{Mg}$、$i$ 为 $\mathrm{Al}$。

### 元素分析

### 元素分析

$\mathrm{W、X、Y、Z}$ 为四种短周期非金属元素，$\mathrm{W}$ 原子中电子排布已充满的能级数与最高能级中的电子数相等，则基态 $\mathrm{W}$ 原子的电子排布式可能为 $1s^22s^22p^2$ 或 $1s^22s^22p^63s^23p^4$，即 $\mathrm{W}$ 为 $\mathrm{C}$ 或 $\mathrm{S}$；若 $\mathrm{W}$ 为 $\mathrm{C}$，$\mathrm{X}$ 与 $\mathrm{W}$ 同族，则 $\mathrm{X}$ 为 $\mathrm{Si}$，$\mathrm{Y}$ 与 $\mathrm{X}$ 相邻且 $\mathrm{Y}$ 原子比 $\mathrm{X}$ 原子多一个未成对电子，则 $\mathrm{Y}$ 为 $\mathrm{P}$，$\mathrm{Z}$ 位于 $\mathrm{W}$ 的对角线位置且为非金属元素，则 $\mathrm{Z}$ 也为 $\mathrm{P}$，与 $\mathrm{Y}$ 重复，不符合题意，故 $\mathrm{W}$ 应为 $\mathrm{S}$；$\mathrm{X}$ 与 $\mathrm{W}$ 同族，则 $\mathrm{X}$ 为 $\mathrm{O}$，$\mathrm{Y}$ 与 $\mathrm{X}$ 相邻且 $\mathrm{Y}$ 原子比 $\mathrm{X}$ 原子多一个未成对电子，则 $\mathrm{Y}$ 为 $\mathrm{N}$，$\mathrm{Z}$ 位于 $\mathrm{W}$ 的对角线位置，则 $\mathrm{Z}$ 为 $\mathrm{F}$。

**解析**

A 项，基态 $\mathrm{O}$ 原子失去 $1$ 个电子后的电子排布式为 $1s^22s^22p^3$，$2p$ 能级为半充满状态，较稳定，继续失去 $1$ 个电子所需能量较高，基态 $\mathrm{N}$ 原子失去 $1$ 个电子后的电子排布式为 $1s^22s^22p^2$，继续失去 $1$ 个电子所需能量较低，故第二电离能：$\mathrm{X(O)>Y(N)}$，错误；

B 项，同主族元素从上到下原子半径逐渐增大，同周期主族元素从左到右原子半径逐渐减小，则原子半径：$\mathrm{Z(F)<W(S)}$，正确；

C 项，$\mathrm{N_2}$ 与 $\mathrm{F_2}$ 均为分子晶体，相对分子质量越大，范德华力越强，沸点越高，故沸点：$\mathrm{N_2<F_2}$，正确；

D 项，同主族元素从上到下电负性逐渐变小，则电负性：$\mathrm{W(S)<X(O)}$，正确。

## 三年模拟

**8.B**　$\mathrm{W、Y、Z}$ 的质子数分别为 $2、8、1$，则 $\mathrm{W、Y、Z}$ 分别为 $\mathrm{He、O、H}$；根据质子数守恒可知 $2+b=8+1$、$90=c+(-1)$，解得 $b=7$、$c=91$，故 $c=13b$，A 正确。$\mathrm{X}$ 的质子数为 $7$，则 $\mathrm{X}$ 为 $\mathrm{N}$；$\mathrm{X、Y、Z}$ 形成的单质分子为 $\mathrm{N_2、O_2、O_3、H_2}$ 等，其中 $\mathrm{N_2、O_2、H_2}$ 为非极性分子，$\mathrm{O_3}$ 为极性分子，B 错误。根据质量数守恒可知 $234=d+0$，则 $d=234$，${}^{234}_{90}\mathrm{Q}$、${}^{d}_{c}\mathrm{R}$ 的质子数不同、质量数相同，为不同元素的不同核素，C 正确。电子的空间运动状态数等于所占据的原子轨道数，基态 $\mathrm{He}$ 原子和 $\mathrm{H}$ 原子均只有 $1s$ 轨道，故空间运动状态数相等，D 正确。

**9.C**

### 元素分析

$\mathrm{M}$ 为短周期失电子能力（即金属性）最强的元素，则 $\mathrm{M}$ 为 $\mathrm{Na}$。$\mathrm{Q}$ 位于第四周期且基态 $\mathrm{Q^{2+}}$ 最高能级轨道为半充满，则基态 $\mathrm{Q^{2+}}$ 的价电子排布式为 $3d^5$，基态 $\mathrm{Q}$ 原子的价电子排布式为 $3d^54s^2$，则 $\mathrm{Q}$ 为 $\mathrm{Mn}$。$\mathrm{Q}$ 的质子数比 $\mathrm{Z}$ 多 $2$，则 $\mathrm{Z}$ 为 $\mathrm{V}$。$\mathrm{X}$ 与 $\mathrm{M(Na)}$ 均位于第三周期，该周期元素第一电离能大小顺序为 $\mathrm{Ar>Cl>P>S>Si>Mg>Al>Na}$，已知该周期第一电离能大于 $\mathrm{X}$ 的元素有两种，则 $\mathrm{X}$ 为 $\mathrm{P}$。$\mathrm{Y}$ 元素基态原子最外层电子数是次外层的三倍，则 $\mathrm{Y}$ 为 $\mathrm{O}$。

**解析**　同周期主族元素从左到右原子半径逐渐减小，同主族元素从上到下原子半径逐渐增大，则原子半径：$\mathrm{Na>P>O}$，A 项正确。基态 $\mathrm{P}$ 原子的价电子排布式为 $3s^23p^3$，根据洪特规则，最高能级 $3p$ 上的 $3$ 个电子分占不同轨道且自旋方向相同，B 项正确。$\mathrm{PH_3}$ 和 $\mathrm{H_2O}$ 均属于分子晶体，$\mathrm{H_2O}$ 存在分子间氢键，故沸点：$\mathrm{H_2O>PH_3}$，C 项错误。$\mathrm{MnO_2}$ 与浓盐酸共热时可发生反应：$\mathrm{MnO_2}+4\mathrm{HCl}\text{(浓)}\xrightarrow{\Delta}\mathrm{MnCl_2}+\mathrm{Cl_2}\uparrow+2\mathrm{H_2O}$，D 项正确。

**10.C**

### 元素分析

四种元素均为短周期主族元素，$\mathrm{Y}$ 的原子序数是 $\mathrm{Z}$ 的两倍，则 $\mathrm{Z}$ 位于第一周期或第二周期（若 $\mathrm{Z}$ 位于第三周期，$\mathrm{Y}$ 的原子序数将大于或等于 $22$）。$\mathrm{W、Z、X}$ 的原子序数依次增大且基态原子核外电子的空间运动状态数（即电子占有的原子轨道数）相同，则 $\mathrm{W}$ 为 $\mathrm{N}$，$\mathrm{Z}$ 为 $\mathrm{O}$，$\mathrm{X}$ 为 $\mathrm{F}$，三者基态原子核外电子的空间运动状态数均为 $1+1+3=5$。$\mathrm{Y}$ 的原子序数是 $\mathrm{Z}$（$\mathrm{O}$，原子序数为 $8$）的两倍，则 $\mathrm{Y}$ 为 $\mathrm{S}$（原子序数为 $16$）。

**解析**　$\mathrm{S}$ 和 $\mathrm{O}$ 的简单氢化物分别为 $\mathrm{H_2S}$ 和 $\mathrm{H_2O}$，两者的中心原子均采取 $sp^3$ 杂化，分子的空间结构均为 V 形，均为极性分子，电负性：$\mathrm{O>S}$，键的极性：$\mathrm{O—H>S—H}$，故分子极性：$\mathrm{H_2O>H_2S}$，A 项错误。电负性：$\mathrm{O>N}$，第一电离能：$\mathrm{N>O}$，B 项错误。$\mathrm{F}$ 位于第二周期，第二周期元素中 $\mathrm{F}$ 的非金属性最强，故同周期元素形成的简单氢化物中 $\mathrm{F}$ 的稳定性最强，C 项正确。$\mathrm{S}$ 的氧化物对应的水化物有 $\mathrm{H_2SO_3、H_2SO_4}$，$\mathrm{H_2SO_3}$ 为弱酸，D 项错误。

**11.C**

### 元素分析

$\mathrm{X、Y、Z、Q}$ 是不同周期、原子序数依次增大的前四周期元素，则 $\mathrm{X、Y、Z、Q}$ 分别位于第一、二、三、四周期。由题图可知，$\mathrm{X}$ 能与 $\mathrm{Y}$ 形成共价键，则 $\mathrm{X}$ 为 $\mathrm{H}$。$\mathrm{Y}$ 为第二周期元素，基态原子有 $3$ 个能级（$1s、2s、2p$）且含有 $2$ 个未成对电子（价电子排布式为 $2s^22p^2$ 或 $2s^22p^4$），由题图可知 $1$ 个 $\mathrm{Y}$ 能与 $2$ 个 $\mathrm{X}$ 形成共价键，则 $\mathrm{Y}$ 为 $\mathrm{O}$（$\mathrm{Y}$ 与 $\mathrm{Q}$ 之间应为配位键）。$\mathrm{Z}$ 与 $\mathrm{Y(O)}$ 同主族且为第三周期元素，故 $\mathrm{Z}$ 为 $\mathrm{S}$。$\mathrm{Q}$ 为第四周期元素，$\mathrm{Q^{2+}}$ 核外的 $\mathrm{M}$ 层排布了 $14$ 个电子，则 $\mathrm{Q^{2+}}$ 的电子排布式为 $1s^22s^22p^63s^23p^63d^6$，故 $\mathrm{Q}$ 的电子排布式为 $[\mathrm{Ar}]3d^64s^2$，$\mathrm{Q}$ 为 $\mathrm{Fe}$。题给化合物为 $[\mathrm{Fe(H_2O)_6}]\mathrm{SO_4}$。

**解析**　非金属性：$\mathrm{O>S}$，故简单氢化物的稳定性：$\mathrm{H_2O>H_2S}$，A 项错误。$\mathrm{O}$ 的简单离子为 $\mathrm{O^{2-}}$，第二周期中，$\mathrm{F^-}$ 与 $\mathrm{O^{2-}}$ 的电子层结构相同但 $\mathrm{F^-}$ 的核电荷数更大，故 $\mathrm{F^-}$ 的半径小于 $\mathrm{O^{2-}}$，此外 $\mathrm{Li^+}$ 和 $\mathrm{Be^{2+}}$ 的电子层仅 $1$ 层，半径也小于 $\mathrm{O^{2-}}$，故比 $\mathrm{O^{2-}}$ 半径小的第二周期简单离子不止 $1$ 种，B 项错误。$\mathrm{Fe}$ 为金属元素，故其第一电离能最小；同主族元素从上到下第一电离能逐渐减小，则第一电离能：$\mathrm{O>S>Fe}$，C 项正确。$[\mathrm{Fe(H_2O)_6}]\mathrm{SO_4}$ 中 $[\mathrm{Fe(H_2O)_6}]^{2+}$ 与 $\mathrm{SO_4^{2-}}$ 之间存在离子键，$\mathrm{H_2O}$ 和 $\mathrm{SO_4^{2-}}$ 中存在极性共价键，$\mathrm{Fe^{2+}}$ 与 $\mathrm{H_2O}$ 之间存在配位键，该化合物中不存在非极性共价键，D 项错误。

**12.D**

### 元素分析

已知题图中涉及的元素均为短周期非金属元素，$\mathrm{U}$ 形成 $6$ 个共价键，则 $\mathrm{U}$ 为 $\mathrm{S}$。$\mathrm{Z}$ 形成 $2$ 个共价键，则 $\mathrm{Z}$ 为 $\mathrm{O}$。$\mathrm{Z、Q、U}$ 的电子层数之和为 $7$，则 $\mathrm{Q}$ 的电子层数为 $7-2-3=2$，且 $\mathrm{Q}$ 形成 $1$ 个共价键，则 $\mathrm{Q}$ 为 $\mathrm{F}$。$\mathrm{X}$ 形成 $1$ 个共价键，$\mathrm{Y}$ 形成 $4$ 个共价键，已知原子序数：$\mathrm{X<Y<Z(O)}$，则 $\mathrm{X}$ 为 $\mathrm{H}$，$\mathrm{Y}$ 为 $\mathrm{C}$。$\mathrm{W}$ 形成 $4$ 个共价键，则 $\mathrm{W}$ 为 $\mathrm{Si}$。
