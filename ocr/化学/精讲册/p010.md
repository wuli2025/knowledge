# 第3节　物质的量浓度

## 知识清单

### 一、物质的量浓度的概念及简单计算

**1. 物质的量浓度：**以单位体积溶液里所含溶质 $\mathrm B$ 的物质的量来表示溶液组成的物理量，符号是 $c_{\mathrm B}$，常用单位为 $\mathrm{mol\cdot L^{-1}}$。

**2. 物质的量浓度的简单计算**

（1）利用公式计算：$c_{\mathrm B}=\dfrac{n_{\mathrm B}}{V}$。

（2）利用溶质 $\mathrm B$ 的质量分数（$w$）和溶液的密度（$\rho$，单位为 $\mathrm{g\cdot cm^{-3}}$）计算：$c_{\mathrm B}=\dfrac{1000\cdot\rho\cdot w}{M_{\mathrm B}}$。

（3）有关溶液稀释的计算，根据稀释前后溶液中溶质的物质的量不变进行计算，$c(\text{浓})\cdot V(\text{浓})=c(\text{稀})\cdot V(\text{稀})$。

### 二、以物质的量为中心的各物理量的换算关系

- 物质的量（$\mathrm{mol}$）
  - 各反应物和生成物的物质的量：通过化学方程式换算。
  - 粒子（原子、分子、离子、电子等）数目：
    - 物质的量 $\times N_{\mathrm A}$ → 粒子数目。
    - 粒子数目 $\div N_{\mathrm A}$ → 物质的量。
  - 原子、离子的物质的量：通过化学式换算。
  - 质量（$\mathrm g$）：
    - 物质的量 $\times M(\mathrm{g\cdot mol^{-1}})$ → 质量。
    - 质量 $\div M(\mathrm{g\cdot mol^{-1}})$ → 物质的量。
  - 标准状况下气体的体积（$\mathrm L$）：
    - 物质的量 $\times 22.4\ \mathrm{L\cdot mol^{-1}}$ → 标准状况下气体的体积。
    - 标准状况下气体的体积 $\div 22.4\ \mathrm{L\cdot mol^{-1}}$ → 物质的量。
  - 物质的量浓度（$\mathrm{mol\cdot L^{-1}}$）：
    - 物质的量 $\div$ 溶液体积（$\mathrm L$）→ 物质的量浓度。
    - 物质的量浓度 $\times$ 溶液体积（$\mathrm L$）→ 物质的量。
    - 通过电离方程式 → 溶液中离子的浓度。

### 三、一定物质的量浓度溶液的配制

**1. 所需仪器：**天平（或量筒）、药匙、烧杯、容量瓶、玻璃棒、胶头滴管。[2024 山东 T19（1），2021 山东 T11A]

**2. 配制步骤**

[图：配制氯化钠溶液的操作流程。取用 $\mathrm{NaCl}$，用量筒量取蒸馏水倒入烧杯，用玻璃棒搅拌溶解；冷却后沿玻璃棒将溶液转移至容量瓶；加水，洗涤烧杯和玻璃棒并将洗涤液转入容量瓶；用胶头滴管逐滴加水，视线与凹液面最低处及刻度线相平；塞紧瓶塞，倒转摇匀。图中文字：$\mathrm{NaCl}$、蒸馏水。]

**3. 注意事项**

（1）容量瓶的常用规格有 $100\ \mathrm{mL}$、$250\ \mathrm{mL}$、$500\ \mathrm{mL}$ 和 $1000\ \mathrm{mL}$ 等。选择容量瓶时应遵循“大而近”原则，即容量瓶的容积应等于或略大于所需溶液的体积，例如需用 $240\ \mathrm{mL}$ 某溶液，则应选择 $250\ \mathrm{mL}$ 容量瓶来配制溶液。

（2）容量瓶使用前要先检查是否漏水：向容量瓶中加入适量水，塞紧瓶塞，右手食指顶住瓶塞，左手托住瓶底，将容量瓶倒置，观察瓶口处是否漏水。若不漏水，将容量瓶正立

并将瓶塞旋转 $180$ 度，再次倒置检查是否漏水，若不漏水，即表明容量瓶密封性良好。

（3）转移溶液时，溶液的温度应为室温；需用玻璃棒引流，且玻璃棒下端要靠在刻度线以下。转移溶液后应洗涤烧杯和玻璃棒 $2\sim3$ 次，洗涤液也要转移到容量瓶中。

（4）定容加蒸馏水时若不慎超过刻度线，应重新配制。

（5）容量瓶不干燥及定容摇匀后液面低于刻度线，均对实验结果无影响。

# 考法突破2　化学计算常用方法

## 一、守恒法

[2024 山东 T19（3）（4），2021 山东 T18（3）]

化学反应的实质是原子间的重新组合，所以在化学反应中存在一系列守恒现象，如质量守恒、元素守恒、原子守恒、得失电子守恒、电荷守恒等。利用这些守恒关系解题的方法叫守恒法。利用守恒法解题，不必纠结反应过程的细节，只需考虑始态和终态，从而达到速解、巧解化学试题的目的。

- 物质
  - 化学式：化合物中正化合价总数 $=|\text{负化合价总数}|$。
  - 电解质溶液中的电荷守恒：所有阳离子所带正电荷总数 $=$ 所有阴离子所带负电荷总数。
  - 化学变化 → 化学反应。
- 化学反应
  - 氧化还原反应（遵循）：
    - 单一反应：氧化剂得电子总数 $=$ 还原剂失电子总数。
    - 多个连续反应：找出化合价在变化前后真正变化的物质及所反应的量。
  - 离子反应：等号两边符合电荷守恒。
  - 电化学：
    - 阳（负）极失电子总数 $=$ 阴（正）极得电子总数。
    - 串联的原电池（电解池），各极上转移电子数相等。
  - 表示形式 → 化学方程式。
- 化学方程式
  - 遵循 → 质量守恒定律：
    - 宏观：$m(\text{参加反应的反应物})=m(\text{反应生成的生成物})$。
    - 微观：各元素原子个数守恒。

### 【答题思维模板】

- 明确目标
  - 明确题目要求解的量。
- 分析过程
  - 分析反应过程中物质的变化，找出守恒类型及相关的量。
- 运用守恒
  - 梳理出前后守恒的量，列式计算求解。

## 二、差量法

差量法是依据化学反应前后的某些“差量”（质量差、气体体积差、物质的量差、气体压强差等）与反应物或生成物的量成正比而建立的一种解题方法。此法将“差量”看作化学方程式右端的一项，利用化学反应中反应物或生成物的量与差量成正比，列出比例式，其解题步骤与根据化学方程式列比例式解题相同。

### 【答题思维模板】

1. 明确产生差量的原因，并能根据化学方程式求出理论上的差值（理论差量）；
2. 结合题中的条件求出或表示出实际的差值（实际差量）；
3. 列比例式求解。
