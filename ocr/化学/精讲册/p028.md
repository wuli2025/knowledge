## 2. 镁及其化合物的性质

### （1）镁（$\mathrm{Mg}$）

①物理性质：银白色、有金属光泽的固体，密度、硬度较小，导电性、导热性、延展性良好。

②化学性质

- $\mathrm{Mg}$
  - 与 $\mathrm{N_2}$ 反应：$\mathrm{Mg}\xrightarrow{\mathrm{N_2}\text{，点燃}}\mathrm{Mg_3N_2}$
  - 与 $\mathrm{CO_2}$ 反应：$\mathrm{Mg}\xrightarrow{\mathrm{CO_2}\text{，点燃}}\mathrm{MgO+C}$
  - 与 $\mathrm{O_2}$ 反应：$\mathrm{Mg}\xrightarrow{\mathrm{O_2}\text{，点燃}}\mathrm{MgO}$
  - 与 $\mathrm{H_2O}$ 反应：$\mathrm{Mg}\xrightarrow{\mathrm{H_2O}\text{，煮沸}}\mathrm{Mg(OH)_2+H_2}$
  - 金属化学通性

③用途：用于信号弹和焰火，镁合金用于制造航天部件。

### （2）氧化镁（$\mathrm{MgO}$）

白色粉末，熔点高，可作耐高温、耐火材料，是一种碱性氧化物。

### （3）氢氧化镁［$\mathrm{Mg(OH)_2}$］

白色固体，难溶于水，溶解度小于碳酸镁，是一种中强碱。

### 注意

## 4. 铝及其化合物的性质

### （1）铝（$\mathrm{Al}$）

①物理性质：银白色、有金属光泽的固体，密度、硬度较小，导电性、导热性、延展性良好。

②化学性质

- $\mathrm{Al}$
  - 与 $\mathrm{O_2}$ 反应：
    - 常温：形成致密氧化膜 $\mathrm{Al_2O_3}$。
    - 加热：$\mathrm{Al}\xrightarrow{\mathrm{O_2}\text{，}\Delta}\mathrm{Al_2O_3}$
  - 与强碱反应：$\mathrm{Al}\xrightarrow{\text{强碱}}\mathrm{[Al(OH)_4]^-+H_2}$
  - 与非氧化性酸反应：$\mathrm{Al}\xrightarrow{\text{非氧化性酸}}\mathrm{Al^{3+}+H_2}$
  - 与氧化性酸反应：$\mathrm{Al}\xrightarrow{\text{氧化性酸}}\mathrm{Al^{3+}}+$ 非金属氧化物
  - 与 $\mathrm{Fe_2O_3}$ 反应：$\mathrm{Al}\xrightarrow{\mathrm{Fe_2O_3}\text{，高温}}\mathrm{Al_2O_3+Fe}$

### 注意

铝遇冷的浓硝酸、浓硫酸发生钝化。

③用途：制作导线；铝合金用于制造汽车、飞机、生活用品等。

### （2）氧化铝（$\mathrm{Al_2O_3}$）

①物理性质及用途：白色固体，难溶于水，熔、沸点高；可作耐火材料和冶炼铝的原料。

②化学性质

a. 两性氧化物：$\mathrm{Al_2O_3+6H^+=2Al^{3+}+3H_2O}$、

$\mathrm{Al_2O_3+2OH^-+3H_2O=2[Al(OH)_4]^-}$。

b. 发生分解：$\mathrm{2Al_2O_3}\text{（熔融）}\xrightarrow[\text{冰晶石}]{\text{电解}}\mathrm{4Al+3O_2}\uparrow$。

### （3）氢氧化铝［$\mathrm{Al(OH)_3}$］

①物理性质及用途：白色不溶于水的固体，可用于制药（治疗胃酸过多）。

②两性氢氧化物：$\mathrm{Al(OH)_3+3H^+=Al^{3+}+3H_2O}$、$\mathrm{Al(OH)_3+OH^-=[Al(OH)_4]^-}$。

### （4）四羟基合铝酸钠｛$\mathrm{Na[Al(OH)_4]}$｝

①与少量盐酸反应：$\mathrm{[Al(OH)_4]^-+H^+=Al(OH)_3}\downarrow+\mathrm{H_2O}$。

②与足量盐酸反应：$\mathrm{[Al(OH)_4]^-+4H^+=Al^{3+}+4H_2O}$。

③与足量 $\mathrm{CO_2}$ 反应：$\mathrm{[Al(OH)_4]^-+CO_2=Al(OH)_3}\downarrow+\mathrm{HCO_3^-}$。

④与 $\mathrm{AlCl_3}$ 溶液反应：$\mathrm{3[Al(OH)_4]^-+Al^{3+}=4Al(OH)_3}\downarrow$。

### 归纳总结

①读题时可先对比原料与产品的成分，初步分析生产过程中保留了哪些元素或物质，除去了哪些元素或物质，引入了哪些成分，结合流程图分析杂质元素在哪些工序中被除去。

②比较原料与产品中主要元素的化合价是否一致，若升高或降低，要结合流程图找出生产过程中可能用到的氧化剂或还原剂；若不变，中间过程中加入的氧化剂或还原剂一般是为了除去杂质等。

## 二、化工流程中的操作

### 1. 原料的预处理

[2025 山东 T17（1），2024 山东 T18（1），2021 山东 T17（1）]

- 原料
  - 为什么进行预处理：便于后续操作，更易与杂质分离并得到产品。
  - 怎样预处理：研磨、粉碎、水浸、酸浸、碱浸、盐浸、焙烧等。

| 预处理操作 | 说明 |
| --- | --- |
| 粉碎、研磨、球磨、乳化 | 作用：增大反应物接触面积，加快反应速率，使反应更充分，提高原料利用率 |
| 浸取——作用 | 使原料转化为离子进入溶液中 |
| 浸取——类型 | ①水浸：溶解、过滤，分离溶解性不同的物质 |
| 浸取——类型 | ②酸浸：使原料中的碱性物质、两性物质、活泼金属等进入溶液。注意酸的性质以及对后续操作的影响，如用硫酸浸取，若体系中存在 $\mathrm{Ba^{2+}}$、$\mathrm{Ca^{2+}}$、$\mathrm{Pb^{2+}}$ 等会形成相应的硫酸盐沉淀，过滤可除去，但因 $\mathrm{CaSO_4}$ 微溶，可能会进行二次除杂（除尽 $\mathrm{Ca^{2+}}$）；如用盐酸浸取，需要控制反应温度防止 $\mathrm{HCl}$ 大量挥发，后续若加入 $\mathrm{ClO^-}$、$\mathrm{MnO_4^-}$ 等氧化剂时会与 $\mathrm{Cl^-}$ 反应产生 $\mathrm{Cl_2}$ |

### 2. 反应条件的控制

（1）改变温度 [2025 山东 T17（2），2021 山东 T8C]

①改变反应速率。

②改变物质的溶解度（注意气体溶解度随温度升高而减小）。

③防止物质分解或挥发（$\mathrm{H_2O_2}$、$\mathrm{NH_3\cdot H_2O}$、铵盐、硝酸等易分解，有机溶剂、气体等易挥发）。

④促进或抑制平衡移动（例如水解平衡）。

⑤催化剂的活性在某温度下达到最高。

⑥防止副反应发生。

### 方法技巧 回答温度过低、过高的思路

- 温度过低
  - 反应速率或溶解速率过慢，生产效率低
  - 主反应是吸热反应，平衡逆向移动；反应物转化率（原料利用率）、生成物产率下降
  - 大部分固态物质的溶解度下降
- 温度过高
  - 可能造成物质的分解、挥发或升华
  - 主反应是放热反应，平衡逆向移动，反应物转化率（原料利用率）、生成物产率下降
  - 催化剂活性降低
  - 发生副反应
  - 会使某些物质溶解度下降
  - 导致胶体聚沉
  - 增加能源成本和对设备的要求
