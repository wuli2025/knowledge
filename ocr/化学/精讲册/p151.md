## 四、实验设计类规范语言表述

### 1. 实验设计

从实验原理出发，按操作过程（或方法）、实验现象、实验结论的顺序来表述答案。

答题模板：操作→现象→结论，即取样，加入……→有……生成→说明……

### 2. 实验现象描述

有关化学实验的现象描述不仅要求准确，还要求全面，答题规范可利用下面的模板处理。

（1）溶液：颜色由……变成……；液面上升或下降（形成液面差）；溶液变浑浊；生成（产生）……沉淀；溶液发生倒吸；产生大量气泡；有气体从溶液中逸出等。

（2）固体：固体表面产生大量气泡；固体逐渐溶解；固体逐渐减少；颜色由……变成……等。

（3）气体：生成……色（味）气体；气体由……色变成……色等。

### 3. 仪器或装置的作用

有利于……（这样做的好处），以防止……（不这样做的坏处）。

如①有机实验中玻璃长导管的作用：冷凝回流，有利于提高反应物的利用率。②某瓶的作用：作安全瓶，防止……中的液体倒吸进入……中。③恒压滴液漏斗：平衡气压，便于漏斗中液体顺利进入……中。④尾气吸收：吸收……气体，防止污染空气。

### 4. 原因、理由类

分析试剂的性质、实验目的、装置特点等→结合已有知识进行分析→结论（找出原因）。

<!-- page 152 -->

答题要求：“有理”——化学原理，“有据”——事实依据。可采取以下两种方式解答：①“正说”——“直接原因＋根本目的”；②“反说”——“如果……就……”。

| 操作 | 常见目的 |
|---|---|
| 分批加入 | 一般因反应放热导致反应剧烈，分批加入可以使反应平稳 |
| 缓缓通入气体 | 使气体被充分吸收或充分反应 |
| 加热至恒重 | 确保物质完全分解 |
| 调节溶液 $\mathrm{pH}$ | （1）使某些离子转化为沉淀，而目标离子不转化为沉淀，达到分离的目的<br>（2）抑制某微粒的水解<br>（3）防止某物质在酸性或碱性条件下发生副反应 |
| 控制体系温度——控制低温 | （1）防止某反应物或目标产物分解或挥发，如 $\mathrm{NaHCO_3}$、$\mathrm{NH_4Cl}$、$\mathrm{H_2O_2}$、氨水、浓盐酸、浓硝酸等<br>（2）使平衡移动，如抑制水解<br>（3）避免副反应的发生 |
| 控制体系温度——控制某一温度范围 | （1）低温反应速率慢，温度过高某物质分解或浪费能源等<br>（2）确保催化剂的催化效果，兼顾反应速率和转化率<br>（3）防止副反应的发生，如乙醇消去反应需迅速升温至 $170\ ^\circ\mathrm{C}$，防止 $140\ ^\circ\mathrm{C}$ 时生成乙醚 |
| 控制体系温度——加热 | （1）加速某固体的溶解<br>（2）减小气体生成物的溶解度，使其逸出<br>（3）加快反应速率<br>（4）使平衡移动，如促进水解<br>（5）防止降温时某物质析出或引入新的杂质 |
| 调节体系压强 | （1）改变反应速率，或改变平衡移动的方向<br>（2）减压蒸馏，使液体沸点降低，避免目标产物发生热分解 |
| 反应物配比选择 | 低于配比，反应物转化率低；高于配比，浪费原料 |
| 蒸发、反应时的气体氛围 | 抑制××离子的水解 |
| 末端放置干燥管 | 防止空气中的水蒸气或二氧化碳干扰实验；防止产物水解 |
