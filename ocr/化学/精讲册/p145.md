# 第十四章　实验方案的设计与评价

## 第1节　制备实验方案的设计与评价

## 知识清单

### 一、物质制备实验思维模型

| 环节 | 内容 |
|---|---|
| 制备环节 | 反应装置的选取，反应条件的控制（控温、调节 $\mathrm{pH}$ 等） |
| 分离提纯环节 | 方法的选择，仪器的名称、用法，操作的注意事项，具体做法的目的 |
| 验纯环节 | 针对杂质，取样，加水溶解，加检验试剂，观察现象，得出结论（定性检验） |
| 测纯环节 | 针对产品，设计纯度测定方案（定量测定） |
| 精纯环节 | 方法的选择及实验方案的设计 |

### 注意

① 若反应物或生成物易与空气中的成分反应，反应开始前应先将装置内的空气排尽。

② 制备在空气中易吸水或易水解的物质（如 $\mathrm{Al_2S_3}$、$\mathrm{AlCl_3}$ 等）时，应在制备装置或收集装置的后方接一个干燥装置，防止空气中的水蒸气进入。[2023 山东 T18（1），2022 山东 T18（3），2021 山东 T18（2）]

③ 用液体吸收气体时，若气体的溶解度较大，应增加防倒吸装置。[2024 山东 T19（2）]

### 二、制备实验方案的评价

| 视角 | 内容 |
|---|---|
| 科学性、可行性视角 | ① 原理是否正确、可行<br>② 操作是否安全、合理<br>③ 步骤是否简单、方便<br>④ 反应速率是否合适<br>⑤ 实验效果是否明显 |
| 绿色化学视角 | ① 反应原料是否易得、安全、无毒<br>② 原料利用率以及产率是否较高<br>③ 合成过程是否造成环境污染 |
| 安全性视角 | ① 净化、吸收气体及停止加热时要防倒吸<br>② 进行某些易燃易爆实验时要防爆炸、防氧化、防吸水 |
| 规范性视角 | ① 为减少易挥发液体反应物的损失和充分利用原料，可在反应装置上加装冷凝回流装置（如长玻璃管、冷凝管等）<br>② 易挥发液体产物（导出时可为蒸气）需及时冷却<br>③ 仪器拆卸与组装顺序相反，按照从右向左、从高到低的顺序拆卸<br>④ 其他，如实验操作顺序、试剂加入顺序等 |

### 三、气体制备综合分析

#### 1. 气体制备的装置连接

气体发生装置→气体净化装置→气体干燥装置→气体收集装置→尾气处理装置。

#### 2. 发生装置

选择依据是反应物的状态和反应条件。

[图：气体发生装置分为 A、B、C 三组。A 为固体加热制气装置，试管略向下倾斜，试管口塞有带导气管的橡胶塞，下方用酒精灯加热。B 为固体与液体常温反应制气装置，依次画出分液漏斗与试管组合装置、带孔塑料板的可控制反应装置、启普发生器。C 为加热制气装置，左侧为分液漏斗与圆底烧瓶组合装置，右侧为带温度计的圆底烧瓶装置，两者均接导气管并用酒精灯加热。]

（1）固体 $\xrightarrow{\Delta}$ 气体型（如图 A）

适用于制 $\mathrm{O_2}$、$\mathrm{NH_3}$ 等。

（2）固体＋液体 $\longrightarrow$ 气体型（如图 B）

适用于制 $\mathrm{H_2}$、$\mathrm{CO_2}$、$\mathrm{NO_2}$、$\mathrm{C_2H_2}$、$\mathrm{NO}$ 等。使用启普发生器时，反应物中固体必须为块状且难溶于水，且生成的不能是易溶于水的气体，如制 $\mathrm{H_2}$、$\mathrm{CO_2}$ 时可使用启普发生器。

（3）固体＋液体 $\xrightarrow{\Delta}$ 气体型（或液体 $\xrightarrow{\Delta}$ 气体型）（如图 C）

适用于制 $\mathrm{Cl_2}$、$\mathrm{C_2H_4}$ 等。制 $\mathrm{C_2H_4}$ 时，需将温度控制在 $170\ ^\circ\mathrm{C}$，气体发生装置中应有温度计，选用图 C 中右侧装置。

#### 3. 净化方法

净化装置：根据除杂试剂的性质和状态可选择洗气瓶、球形干燥管、U 形管、硬质玻璃管等。

#### 4. 干燥方法

干燥剂只能吸水而不能与气体发生反应。酸性干燥剂不能干燥碱性气体，碱性干燥剂不能干燥酸性气体，具有强氧化性的干燥剂不能干燥具有还原性的气体（注意浓硫酸可干燥 $\mathrm{H_2}$ 和 $\mathrm{SO_2}$，无水 $\mathrm{CaCl_2}$ 不能干燥 $\mathrm{NH_3}$）。

[2024 山东 T19（2）]

| 类型 | 常用干燥剂 |
|---|---|
| 酸性干燥剂 | 浓硫酸（强氧化性）、$\mathrm{P_2O_5}$ |
| 碱性干燥剂 | 碱石灰 |
| 中性干燥剂 | 无水 $\mathrm{CaCl_2}$ |

#### 5. 收集方法

根据气体的密度、溶解性及是否与水或空气中的 $\mathrm{O_2}$ 等发生反应来确定气体的收集方法。

（1）排水法：适用于不易溶于水且不与水发生反应的气体，如 $\mathrm{O_2}$、$\mathrm{H_2}$、$\mathrm{NO}$、$\mathrm{C_2H_4}$ 等。能溶于水但溶解度不大的气体，可采用排某些饱和溶液的方法收集，如 $\mathrm{Cl_2}$ 可采用排饱和食盐水的方法收集。

（2）排空气法：适用于不与空气中各成分反应的气体。密度比空气大的气体用向上排空气法，如 $\mathrm{O_2}$、$\mathrm{CO_2}$、$\mathrm{Cl_2}$、$\mathrm{SO_2}$、$\mathrm{NO_2}$ 等；密度比空气小的气体用向下排空气法，如 $\mathrm{H_2}$、$\mathrm{NH_3}$ 等。

密度与空气相近的气体不用排空气法收集，如 $\mathrm{CO}$、$\mathrm{N_2}$ 等。

#### 6. 尾气处理

根据尾气性质，选择合适的试剂处理尾气，注意防倒吸。
