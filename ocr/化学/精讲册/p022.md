<!-- page 22 -->

例如，书写酸性 $\mathrm{KMnO_4}$ 溶液与 $\mathrm{SO_2}$ 反应的离子方程式，$\mathrm{KMnO_4}$ 为氧化剂，对应的还原产物为 $\mathrm{Mn^{2+}}$；$\mathrm{SO_2}$ 为还原剂，对应的氧化产物为 $\mathrm{SO_4^{2-}}$。根据得失电子守恒配平变价物质：$\mathrm{2MnO_4^-+5SO_2\longrightarrow 2Mn^{2+}+5SO_4^{2-}}$，该反应在酸性环境中进行，根据电荷守恒，在右边补上 $\mathrm{4H^+}$，根据原子守恒，在左边补上 $\mathrm{2H_2O}$，可得离子方程式：$\mathrm{2MnO_4^-+5SO_2+2H_2O=2Mn^{2+}+5SO_4^{2-}+4H^+}$。在离子方程式左右两边补上 $\mathrm{2K^+}$，将相应离子“配对”，即可得化学方程式：$\mathrm{2KMnO_4+5SO_2+2H_2O=2MnSO_4+K_2SO_4+2H_2SO_4}$。

### 注意

（1）对于中性溶液中发生的反应，配平电荷时一般在生成物一侧加 $\mathrm{H^+}$ 或 $\mathrm{OH^-}$。酸性条件下，离子方程式中不能出现 $\mathrm{OH^-}$；碱性条件下，离子方程式中不能出现 $\mathrm{H^+}$。

（2）记住一些常见物质的转化关系：

① 含氯元素的氧化剂（例如 $\mathrm{ClO^-}$）被还原时，一般考虑生成 $\mathrm{Cl^-}$（题目中暗示有别的产物时除外）。

② 金属硫化物（例如 $\mathrm{CuS}$）在空气中灼烧，一般考虑生成金属氧化物与 $\mathrm{SO_2}$。

③ 含 $-2$ 价硫元素的物质（例如 $\mathrm{S^{2-}}$）在溶液中被氧化，一般考虑生成 $\mathrm{S}$。

④ 含 $+4$ 价硫元素的物质（例如 $\mathrm{SO_3^{2-}}$）被氧化，一般考虑生成 $\mathrm{SO_4^{2-}}$。

⑤ 含负价氮元素的还原剂（如 $\mathrm{N_2H_4}$）被氧化时，一般考虑生成 $\mathrm{N_2}$。

# 第三章 金属及其化合物

## 第1节 钠及其化合物

## 知识清单

### 一、钠及其化合物

### 1. 钠

（1）物理性质及保存方式：质软、银白色、有金属光泽，导电性、导热性良好，密度 $\rho_{\text{煤油}}<\rho_{\text{钠}}<\rho_{\text{水}}$，熔点较低；保存在煤油或石蜡油中。

（2）化学性质及制备

- $\mathrm{NaCl}$（熔融）$\xrightarrow{\text{电解}}\mathrm{Na}$。
- $\mathrm{Na}$：
  - 与 $\mathrm{Cl_2}$ 反应：$\mathrm{Na}\xrightarrow{\mathrm{Cl_2},\,\Delta}\mathrm{NaCl}$。
  - 与 $\mathrm{O_2}$ 反应：
    - 加热：$\mathrm{Na}\xrightarrow{\mathrm{O_2},\,\Delta}\mathrm{Na_2O_2}$。
    - 不加热：$\mathrm{Na}\xrightarrow{\mathrm{O_2}}\mathrm{Na_2O}$。
  - 与 $\mathrm{CuSO_4}$ 溶液反应：$\mathrm{Na}\xrightarrow{\mathrm{CuSO_4}\text{溶液}}\mathrm{Cu(OH)_2+H_2+Na_2SO_4}$。
  - 与 $\mathrm{HCl}$ 或 $\mathrm{H_2SO_4}$ 反应：$\mathrm{Na}\xrightarrow{\mathrm{HCl}\text{或}\mathrm{H_2SO_4}}\mathrm{Na^++H_2}$。
  - 与 $\mathrm{H_2O}$ 反应：$\mathrm{Na}\xrightarrow{\mathrm{H_2O}}\mathrm{NaOH+H_2}$。

（3）用途：① 冶炼金属；② 高压钠灯；③ 钠钾合金用作原子反应堆的导热剂。

### 注意

钠不能保存在 $\mathrm{CCl_4}$ 中，因为 $\mathrm{CCl_4}$ 的密度比钠的大，钠会浮在 $\mathrm{CCl_4}$ 表面，与空气接触而变质。

### 2. 钠的氧化物

（1）氧化钠（$\mathrm{Na_2O}$）：白色固体，碱性氧化物。

与水反应：$\mathrm{Na_2O+H_2O=2NaOH}$。

与 $\mathrm{CO_2}$ 反应：$\mathrm{Na_2O+CO_2=Na_2CO_3}$。

（2）过氧化钠（$\mathrm{Na_2O_2}$）：淡黄色固体，常用作漂白剂、消毒剂、供氧剂。[2025 山东 T5B]

电子式：$\mathrm{Na^+}\left[:\overset{\cdot\cdot}{\underset{\cdot\cdot}{\mathrm{O}}}:\overset{\cdot\cdot}{\underset{\cdot\cdot}{\mathrm{O}}}:\right]^{2-}\mathrm{Na^+}$。

与水反应：$\mathrm{2Na_2O_2+2H_2O=4NaOH+O_2\uparrow}$。

与 $\mathrm{CO_2}$ 反应：$\mathrm{2Na_2O_2+2CO_2=2Na_2CO_3+O_2}$。

### 3. $\mathrm{Na_2CO_3}$ 与 $\mathrm{NaHCO_3}$

（1）$\mathrm{Na_2CO_3}$ 俗名纯碱、苏打；$\mathrm{NaHCO_3}$ 俗名小苏打。

（2）物理性质：均为白色固体，易溶于水，溶解度 $\mathrm{Na_2CO_3}>\mathrm{NaHCO_3}$。溶于水时 $\mathrm{Na_2CO_3}$ 放热、$\mathrm{NaHCO_3}$ 吸热。

（3）化学性质

① 水溶液均呈碱性；同浓度时碱性：$\mathrm{Na_2CO_3}>\mathrm{NaHCO_3}$。

② 热稳定性：$\mathrm{Na_2CO_3}>\mathrm{NaHCO_3}$。

$\mathrm{2NaHCO_3}\xrightarrow{\Delta}\mathrm{Na_2CO_3+CO_2\uparrow+H_2O}$。

③ 与盐酸反应：$\mathrm{Na_2CO_3+2HCl=2NaCl+H_2O+CO_2\uparrow}$，$\mathrm{NaHCO_3+HCl=NaCl+H_2O+CO_2\uparrow}$（盐酸逐滴加入时 $\mathrm{NaHCO_3}$ 先产生气泡）。

（4）相互转化 [2022 山东 T11A]

- $\mathrm{Na_2CO_3}\xrightarrow{\mathrm{CO_2}\text{和水（或少量 }\mathrm{H^+}\text{）}}\mathrm{NaHCO_3}$。
- $\mathrm{NaHCO_3}\xrightarrow{\Delta\text{（或 }\mathrm{NaOH}\text{）}}\mathrm{Na_2CO_3}$。

（5）用途：$\mathrm{Na_2CO_3}$ 用于纺织、制肥皂、造纸、制玻璃等；$\mathrm{NaHCO_3}$ 用于制药、焙制糕点等。

[2025 山东 T2D]

（6）$\mathrm{Na_2CO_3}$ 与 $\mathrm{NaHCO_3}$ 的鉴别方法

① 利用热稳定性不同

- 固体 → 加热：
  - 无明显变化的是 $\mathrm{Na_2CO_3}$。
  - 放出无色无味且能使澄清石灰水变浑浊的气体的是 $\mathrm{NaHCO_3}$。

② 利用和酸反应生成气体的现象不同

- 溶液 → 滴加盐酸：
  - 立即产生气泡的是 $\mathrm{NaHCO_3}$。
  - 开始时不产生气泡的是 $\mathrm{Na_2CO_3}$。

③ 利用溶液的碱性不同

- 溶液 → 测相同浓度溶液的 $\mathrm{pH}$：
  - $\mathrm{pH}$ 大（碱性强）的为 $\mathrm{Na_2CO_3}$。
  - $\mathrm{pH}$ 小（碱性弱）的为 $\mathrm{NaHCO_3}$。

### 4. 焰色试验

（1）本质：电子的跃迁，属于物理变化。

（2）实验步骤：铂丝 $\xrightarrow{\text{用盐酸洗涤}}\xrightarrow{\text{灼烧}}$ 无色 $\xrightarrow{\text{蘸取待测物}}\xrightarrow{\text{灼烧}}$ 观察火焰颜色 $\xrightarrow{\text{用盐酸洗涤}}\xrightarrow{\text{灼烧}}$ 无色。

也可用光洁无锈的铁丝代替铂丝。

（3）常见金属元素的焰色

$\mathrm{Na}$ 为黄色；$\mathrm{K}$ 为紫色（透过蓝色钴玻璃观察）；$\mathrm{Ca}$ 为砖红色；$\mathrm{Cu}$ 为绿色。
